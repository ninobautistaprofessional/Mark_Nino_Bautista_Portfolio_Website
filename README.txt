MARK NIÑO A. BAUTISTA — PORTFOLIO WEBSITE

Files:
- index.html: complete responsive portfolio website, including styling and mobile navigation.

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish:
- Upload index.html to the public web root of your hosting provider (often public_html).
- If using GitHub Pages, create a repository and upload index.html, then enable Pages in repository settings.
- If using Hostinger, upload the file to public_html using File Manager.

Before publishing:
- Verify that your phone number and email are correct.
- Confirm your exact contribution to each website and adjust the project descriptions. The site avoids claiming that you personally built the ticketing or job-order systems without confirmation.
- Add approved screenshots and any portfolio assets you want to showcase.
